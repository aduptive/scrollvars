Total CPU and frame delivery

Three ScrollVars rows. The plain one is the default: the document outputs --sv-page/--sv-v publish only when a stylesheet reads them, and nothing here does. The styles/scoped.css row is the opt-in that stops the clocks inheriting (README, Scoped clocks), run with the two author lines its contract asks of this fixture: it pays on this flat profile and wins on the deep one below. The "document variables published" row is what the two document outputs cost when a page reads them, not a competitor comparison. Use the batched GSAP row when comparing one tracker per section.
